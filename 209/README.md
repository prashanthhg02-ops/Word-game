# Wordsmith

A small, responsive browser word game. Guess the hidden five-letter word in six tries.

## Play

Open `index.html` in a modern web browser. No installation or build step is required.

## How it works

- Enter a five-letter guess using your keyboard or the on-screen keyboard.
- Press **Enter** to submit a guess.
- Green tiles show letters in the correct position.
- Gold tiles show letters in the word, but in a different position.
- Muted tiles show letters that are not in the word.
- Solve the puzzle within six guesses. Choose **Play again** to start a new game.

Game totals, win rate, and current streak are saved in your browser's local storage.
